PVE 从零安装四网口 VyOS 软路由：PPPoE、DHCP、FakeIP 与安全防火墙

从 PVE 创建虚拟机和安装 VyOS 开始，逐步配置四网口桥接、PPPoE、IPv4/IPv6、DHCP、DNS、FakeIP 策略路由和默认拒绝防火墙，并附完整配置。

本文从一台有四个物理网口的小主机开始，说明如何在 Proxmox VE（PVE）里创建 VyOS 虚拟机、安装系统，再配置为家用主路由。示例按以下端口规划：

VyOS 网卡PVE 网桥用途
eth0vmbr0LAN 口 1
eth1vmbr1LAN 口 2
eth2vmbr2LAN 口 3
eth3vmbr3WAN，连接光猫

前三个 LAN 口在 VyOS 内桥接成 br0。LAN 网段为 10.20.20.0/24，网关和 DNS 为 10.20.20.1；FakeIP 上游 sing-box/MosDNS 地址示例为 10.20.20.6 和 fd88::6666。若你的网段、设备或网卡顺序不同，请先替换示例值。

文章基于 VyOS rolling 2026.11.20-0016 的命令树。PPPoE 用户名和密码使用占位符，必须换成自己的值。主配置不包含任何公网端口转发；端口转发放在末尾作为可选示例。

一、在 PVE 确认网卡与网桥#

先在 PVE Shell 查看物理网卡名：

ip -br link

根据网卡 MAC 地址和插拔测试，确认哪一个接口对应小主机的 WAN、LAN 端口。PVE 中需要先创建 vmbr0 到 vmbr3 四个 Linux Bridge：前三个桥分别连接三个 LAN 物理口，vmbr3 连接 WAN 物理口。只有 LAN 管理桥配置 PVE 管理地址；不要把 PVE 管理 IP 配在 WAN 桥上。

桥接关系示意：

LAN 物理口 1 ─ vmbr0 ─ VyOS eth0 ┐
LAN 物理口 2 ─ vmbr1 ─ VyOS eth1 ├─ VyOS br0 ─ 家庭 LAN
LAN 物理口 3 ─ vmbr2 ─ VyOS eth2 ┘
光猫             ─ vmbr3 ─ VyOS eth3 ─ PPPoE

如果 PVE 本身已通过 RouterOS 或其他路由器上网，先保留该管理通路。PVE 的 LAN/WAN 网桥建好后，再创建 VyOS VM；不要把两台配置了相同 LAN 网关地址的路由器同时接入同一 LAN。

二、从 PVE Shell 创建 VyOS 虚拟机#

下载 VyOS rolling ISO 并上传到 PVE 的 ISO 存储。PVE 官方命令行工具 qm 用于创建和管理 QEMU 虚拟机；存储名称按你的 PVE 实际配置调整。

先确认 ISO 与存储名称：

pvesm status
ls -lh /var/lib/vz/template/iso/

下面以 VMID 188、ISO 文件名 vyos-rolling.iso、系统盘存储 local-lvm 为例。若你的存储叫 local，请替换命令中的 local-lvm；ISO 存储通常是 local。

qm create 188 \
  --name vyos-router \
  --memory 2048 \
  --cores 4 \
  --cpu host \
  --machine q35 \
  --bios ovmf \
  --scsihw virtio-scsi-single \
  --ostype l26 \
  --net0 virtio,bridge=vmbr0 \
  --net1 virtio,bridge=vmbr1 \
  --net2 virtio,bridge=vmbr2 \
  --net3 virtio,bridge=vmbr3

qm set 188 --efidisk0 local-lvm:0,efitype=4m,pre-enrolled-keys=0
qm set 188 --scsi0 local-lvm:12,discard=on,iothread=1,ssd=1
qm set 188 --ide2 local:iso/vyos-rolling.iso,media=cdrom
qm set 188 --serial0 socket --vga serial0
qm set 188 --boot 'order=scsi0;ide2'
qm set 188 --onboot 1 --startup order=1,up=30

四张网卡使用 VirtIO，PVE 里的 net0 到 net3 顺序对应 VyOS 的 eth0 到 eth3。如果 PVE 已有 VMID 188，请换一个未使用的编号。2 GB 内存、4 vCPU、12 GB 系统盘是本文配置的起点。

三、安装 VyOS 到虚拟磁盘#

启动虚拟机并打开 PVE 的 Console。VyOS live ISO 默认登录用户名和密码都是 vyos。登录后运行安装程序：

install image

安装向导会要求为安装到磁盘后的 vyos 用户设置新密码；设置并确认一个强密码，再选择系统盘 vda 并确认安装。安装完成后重启，重启前从 PVE 硬件设置中卸载 ISO，避免再次进入 live 系统。此时登录用户名仍是 vyos，密码是刚才在安装向导中设置的新密码，不再是默认的 vyos。默认 live 登录凭据和安装步骤见 VyOS 官方安装文档。登录后检查版本和接口：

show version
show interfaces ethernet

此时确认物理 WAN 确实对应 eth3，三个 LAN 对应 eth0、eth1、eth2。若顺序不同，下面所有接口名都要按实际情况替换。

四、设置主机、管理账户与时间#

进入配置模式：

configure

设置主机名、时区、SSH 和 NTP。jay 是示例管理账户，<替换为强密码> 必须替换为自己的管理密码，不要照抄占位符：

set system host-name 'vyos-router'
set system time-zone 'Asia/Shanghai'
set system login user jay full-name 'Router Administrator'
set system login user jay authentication plaintext-password '<替换为强密码>'
set service ssh port '22'
set service ntp server '129.250.35.251'
set service ntp server '203.107.6.88'

建议先确认新账户可以登录，再禁用默认 vyos 账户：

set system login user vyos disable

SSH 仅从可信 LAN 开放；本文稍后的 input 防火墙默认拒绝 WAN 对路由器本机的访问。

五、桥接三个 LAN 口并配置 WAN PPPoE#

给 LAN 创建桥 br0，三个 LAN 接口加入桥接；eth3 连接光猫。示例光猫地址是 192.168.1.1/24，VyOS 管理光猫的地址是 192.168.1.3/24，按光猫实际网段修改：

set interfaces bridge br0 description 'LAN bridge'
set interfaces bridge br0 address '10.20.20.1/24'
set interfaces bridge br0 address 'fd88::1111/64'
set interfaces bridge br0 member interface 'eth0'
set interfaces bridge br0 member interface 'eth1'
set interfaces bridge br0 member interface 'eth2'
set interfaces bridge br0 stp
set interfaces bridge br0 ip adjust-mss 'clamp-mss-to-pmtu'
set interfaces bridge br0 ipv6 adjust-mss 'clamp-mss-to-pmtu'

set interfaces ethernet eth3 description 'WAN to optical modem'
set interfaces ethernet eth3 address '192.168.1.3/24'

set interfaces pppoe pppoe0 description 'ISP PPPoE WAN'
set interfaces pppoe pppoe0 source-interface 'eth3'
set interfaces pppoe pppoe0 authentication username '<PPPOE_USERNAME>'
set interfaces pppoe pppoe0 authentication password '<PPPOE_PASSWORD>'
set interfaces pppoe pppoe0 mtu '1492'
set interfaces pppoe pppoe0 mru '1492'
set interfaces pppoe pppoe0 no-peer-dns
set interfaces pppoe pppoe0 ip adjust-mss 'clamp-mss-to-pmtu'
set interfaces pppoe pppoe0 ipv6 adjust-mss 'clamp-mss-to-pmtu'

把尖括号中的 PPPoE 用户名和密码替换为运营商提供的真实凭据。不要把真实值发到公开文章或截图中。no-peer-dns 表示不使用运营商自动下发的 DNS，后面会明确配置 DNS 上游。

六、配置 DHCP、DNS 转发和内网域名#

DHCP 地址池使用 10.20.20.100–10.20.20.254，租约 12 小时；路由器自身作为 LAN DNS 转发器，上游 10.20.20.6 是 FakeIP DNS 服务示例：

set service dhcp-server shared-network-name LAN authoritative
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 subnet-id '1'
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 lease '43200'
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 option default-router '10.20.20.1'
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 option name-server '10.20.20.1'
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 range 0 start '10.20.20.100'
set service dhcp-server shared-network-name LAN subnet 10.20.20.0/24 range 0 stop '10.20.20.254'

set service dns forwarding allow-from '10.20.20.0/24'
set service dns forwarding allow-from 'fd88::/64'
set service dns forwarding listen-address '10.20.20.1'
set service dns forwarding listen-address 'fd88::1111'
set service dns forwarding name-server '10.20.20.6'
set service dns forwarding name-server 'fd88::6666'
set system name-server '10.20.20.6'
set system name-server 'fd88::6666'

allow-from 限制哪些网段能使用路由器 DNS，避免把 DNS 转发器开放给 WAN。上游地址要换成你自己的 MosDNS/sing-box DNS；若没有 FakeIP DNS，可替换为可信递归 DNS。

七、开启 IPv6 前缀委派与 LAN RA#

以下假设运营商通过 PPPoE 下发 DHCPv6 Prefix Delegation（PD）。请求一个 /64 给 br0，并让 LAN 客户端通过 Router Advertisement（RA）自动配置 IPv6：

set interfaces pppoe pppoe0 ipv6 address autoconf
set interfaces pppoe pppoe0 dhcpv6-options pd 0 length '64'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface br0 address '1'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface br0 sla-id '0'

set service router-advert interface br0 prefix '::/64'
set service router-advert interface br0 prefix '::/64' preferred-lifetime '14400'
set service router-advert interface br0 prefix '::/64' valid-lifetime '86400'
set service router-advert interface br0 name-server 'fd88::6666'

若运营商不提供 IPv6 PD，可先跳过本节及后面的 IPv6 FakeIP 路由配置；IPv4 PPPoE、DHCP 和 NAT 仍可单独工作。不要把示例 ULA fd88::/64 当成公网 IPv6 前缀。

十、首次提交、检查与保存#

首次启用主路由配置前，确认 WAN/LAN 网卡已接对，PPPoE 凭据已替换。用带自动回滚的提交测试，再检查拨号、地址、DHCP 和 DNS：

commit-confirm 5

commit-confirm 5 会先临时提交候选配置，并启动 5 分钟确认计时器。请在这 5 分钟内检查并输入 confirm，计时器才会取消；如果超时未确认，VyOS 默认会重启并加载此前保存的配置。因此它适合远程修改防火墙、网卡等可能切断管理连接的设置。VyOS 当前版本也可把超时动作改为重新加载旧配置，默认动作是重启回到已保存配置，详见官方 CLI 文档。

在提示中输入 Y。然后检查：

run show interfaces pppoe pppoe0
run show ip route 0.0.0.0/0
run show dhcp server leases
run show log | match kea

在 LAN 客户端测试：

ipconfig getpacket en0                 # macOS；查看 DHCP 网关/DNS
nslookup example.com 10.20.20.1
curl -I https://example.com

确认 PPPoE 已连接、客户端拿到 10.20.20.x、默认网关/DNS 是 10.20.20.1、网页能打开后，回到 VyOS 配置模式确认并保存：

confirm
save
exit

不要在网络还未验证时执行 confirm。如果自动回滚时间到，VyOS 会恢复提交前配置。

十一、可选：添加单台设备的公网端口转发#

端口转发不是通用路由器配置。只为确实需要从公网访问的服务增加规则，并同时限制目标主机、协议和端口。以下示例把 Matrix HTTPS 端口 12335/TCP 转到 10.20.20.8。先在服务主机确认应用确实监听该端口，再配置：

configure
set nat destination rule 200 description 'Matrix HTTPS example'
set nat destination rule 200 inbound-interface name 'pppoe0'
set nat destination rule 200 protocol 'tcp'
set nat destination rule 200 destination port '12335'
set nat destination rule 200 translation address '10.20.20.8'
commit-confirm 5

验证外部客户端能连接后运行 confirm、save。本例的 forward 规则按 connection-status nat destination 识别已匹配 DNAT 的新连接；不要为了“端口转发方便”把 WAN 到 LAN 全部放行。

IPv6 动态公网前缀下的入站放行示例#

IPv6 通常不做 NAT：公网请求直接到达内网服务器的全局 IPv6 地址，VyOS 只在 forward 防火墙中精确放行。运营商委派的前缀会变化，因此不要把完整公网 IPv6 地址写进规则。下面用 destination address-mask 只比较地址后 64 位（接口标识），忽略动态前缀。

示例假定 Matrix VM 的 MAC 派生接口标识为 ::be24:11ff:fe04:3c5d，开放 TCP 12335 和可选 UDP 中继端口；Syncthing 主机的接口标识为 ::be24:11ff:fed2:da98，开放 TCP/UDP 22000。请替换成目标服务器实际的后 64 位接口标识和所需端口：

configure
set firewall ipv6 forward filter rule 100 description '发布 Matrix TCP 服务'
set firewall ipv6 forward filter rule 100 action 'accept'
set firewall ipv6 forward filter rule 100 inbound-interface name 'pppoe0'
set firewall ipv6 forward filter rule 100 outbound-interface name 'br0'
set firewall ipv6 forward filter rule 100 destination address '::be24:11ff:fe04:3c5d'
set firewall ipv6 forward filter rule 100 destination address-mask '::ffff:ffff:ffff:ffff'
set firewall ipv6 forward filter rule 100 protocol 'tcp'
set firewall ipv6 forward filter rule 100 destination port '12335'
set firewall ipv6 forward filter rule 100 state 'new'

set firewall ipv6 forward filter rule 110 description '发布 Matrix UDP 中继服务'
set firewall ipv6 forward filter rule 110 action 'accept'
set firewall ipv6 forward filter rule 110 inbound-interface name 'pppoe0'
set firewall ipv6 forward filter rule 110 outbound-interface name 'br0'
set firewall ipv6 forward filter rule 110 destination address '::be24:11ff:fe04:3c5d'
set firewall ipv6 forward filter rule 110 destination address-mask '::ffff:ffff:ffff:ffff'
set firewall ipv6 forward filter rule 110 protocol 'udp'
set firewall ipv6 forward filter rule 110 destination port '3478,50000-50400'
set firewall ipv6 forward filter rule 110 state 'new'

set firewall ipv6 forward filter rule 130 description '发布 Syncthing TCP/UDP 服务'
set firewall ipv6 forward filter rule 130 action 'accept'
set firewall ipv6 forward filter rule 130 inbound-interface name 'pppoe0'
set firewall ipv6 forward filter rule 130 outbound-interface name 'br0'
set firewall ipv6 forward filter rule 130 destination address '::be24:11ff:fed2:da98'
set firewall ipv6 forward filter rule 130 destination address-mask '::ffff:ffff:ffff:ffff'
set firewall ipv6 forward filter rule 130 protocol 'tcp_udp'
set firewall ipv6 forward filter rule 130 destination port '22000'
set firewall ipv6 forward filter rule 130 state 'new'
commit-confirm 5

destination address-mask '::ffff:ffff:ffff:ffff' 让匹配仅看地址低 64 位，所以 PD 前缀变化时不用改防火墙规则。目标设备必须使用稳定的接口标识；如果启用了随机/隐私 IPv6 地址，标识会变化，规则便匹配不到。可在服务器上用 ip -6 addr 查看当前地址，并取其最后四组作为接口标识。只开放明确需要的协议和端口，不要允许整个 LAN 的所有 IPv6 入站。

从外网验证通过后，在 VyOS 配置模式输入 confirm 和 save。没有公网服务需求就不添加这些规则，保持 IPv6 forward 默认拒绝。

Wi‑Fi 内使用公网域名时，如果客户端 DNS 不支持 NAT 回环，可为单个域名添加 LAN 本地记录；本文第六节的 Matrix 记录就是示例。外网移动网络仍使用公网 DNS 和公网入口，两者不要混为一谈。

configure
compare
commit-confirm 5

commit 只使配置生效，save 才会写入启动配置。配置出现问题且尚未提交时，用 discard 放弃候选修改。
